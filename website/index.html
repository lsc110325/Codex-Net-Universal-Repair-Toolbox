主要功能

针对 Codex 在本机代理、沙箱网络和 git 配置上的常见问题。

一键修复

自动探测代理

扫描本机代理端口，验证 HTTP 代理握手与真实出网，再写入 Codex 配置。

环境修复

覆盖黑洞代理

写入 shell_environment_policy.set，避免 Codex 沙箱注入不可用代理。

Git 修复

修复 git TLS

注入 GIT_EXEC_PATH，并把 git TLS 后端切换为 openssl。

安全

备份与回滚

修改 config.toml、.env 和 .gitconfig 前自动备份，可一键还原。

诊断

全面自检

检查端口、出网、配置、环境变量、git 和回环保护等关键状态。

个性化

快捷键设置

支持开关快捷键，并逐项自定义修复、自检、重启和更多页快捷键。

更多工具

适合第一次使用，也适合遇到问题后快速定位。

实用工具

启动代理软件

自动发现 FlClash、iKuuu、v2rayN、Hiddify 等程序，也可以手动选择代理 exe。

诊断

代理测速

测试百度、GitHub、OpenAI 域名的代理连接延迟。

备份

配置快照

备份与恢复 config.toml、.env、.gitconfig。
